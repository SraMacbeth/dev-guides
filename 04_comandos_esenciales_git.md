# Guía — Comandos esenciales de Git

## Objetivo

Tener una referencia rápida de los comandos Git más importantes para el trabajo diario.


---

## Estado

```bash
git status
```

## Agregar archivos

```bash
git add .
```

## Commit

```bash
git commit -m "mensaje"
```

## Push

```bash
git push
```

## Pull

```bash
git pull
```

## Branches

```bash
git branch
git checkout -b nueva-rama
```

## Merge

```bash
git merge nombre-rama
```
