# Guías de Desarrollo Python para Perfil Junior

Repositorio personal de guías prácticas orientadas a desarrollo Python, organización de proyectos y flujo de trabajo profesional.

El objetivo de este repositorio es construir una base sólida y progresiva de conocimientos aplicados al desarrollo real, especialmente desde la perspectiva de una desarrolladora autodidacta que busca profesionalizar su flujo de trabajo y prepararse para su primer puesto junior.

---

# Objetivos del proyecto

Estas guías buscan:

- estructurar procesos de desarrollo de forma clara y repetible
- reducir errores frecuentes
- documentar flujos de trabajo reales
- incorporar buenas prácticas profesionales
- mejorar organización mental y técnica
- facilitar debugging y mantenimiento
- crear hábitos sólidos de desarrollo

---
	
# Perfil al que están orientadas

Principalmente pensado para:

- desarrolladores/as Python autodidactas
- nivel inicial/intermedio
- proyectos personales
- portfolio junior

Tecnologías y herramientas abordadas:

- Python
- SQLite
- Git y GitHub
- Testing con unittest
- Linux / Debian

# Filosofía de estas guías

La prioridad no es escribir código "perfecto".

La prioridad es:

- terminar proyectos
- desarrollar consistencia
- aprender procesos reales
- construir experiencia práctica
- mejorar progresivamente

Estas guías están escritas con enfoque práctico, explícito y gradual, intentando minimizar ambigüedades y contradicciones.
