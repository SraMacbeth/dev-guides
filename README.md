# Guías de Desarrollo Python para Perfil Junior

> 📚 Colección de guías prácticas sobre Git, Python y buenas prácticas de desarrollo, construidas a partir del aprendizaje autodidacta y la experiencia desarrollando proyectos reales.

Repositorio personal de guías orientadas al desarrollo en Python, la organización de proyectos y la adopción de un flujo de trabajo profesional.

El objetivo de este repositorio es construir una base de conocimientos práctica y progresiva, especialmente pensada para desarrolladores/as autodidactas que desean profesionalizar su forma de trabajar y prepararse para su primer puesto como desarrollador/a junior.

---

# Objetivos del proyecto

Estas guías buscan:

- Estructurar procesos de desarrollo de forma clara y repetible.
- Reducir errores frecuentes.
- Documentar flujos de trabajo reales.
- Incorporar buenas prácticas profesionales.
- Mejorar la organización técnica y mental.
- Facilitar el debugging y el mantenimiento.
- Crear hábitos sólidos de desarrollo.

---

# Perfil al que están orientadas

Principalmente pensado para:

- Desarrolladores/as Python autodidactas.
- Nivel inicial e intermedio.
- Proyectos personales.
- Portfolio junior.

# Recomendación general

La idea es construir capas progresivas de profesionalización:

1. Aprender Git y GitHub.
2. Organizar correctamente el flujo de trabajo.
3. Escribir código limpio y mantenible.
4. Comprender bases de datos.
5. Incorporar debugging sistemático.
6. Aprender testing.
7. Construir proyectos cada vez más sólidos.

---

# Filosofía de estas guías

La prioridad no es escribir código "perfecto".

La prioridad es:

- Terminar proyectos.
- Desarrollar consistencia.
- Aprender procesos reales.
- Construir experiencia práctica.
- Mejorar progresivamente.

Estas guías están escritas con un enfoque práctico, explícito y gradual, intentando minimizar ambigüedades y contradicciones.
